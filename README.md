# MongoDB Analysis – Goodreads Choice Awards 2024

This project analyzes the Goodreads Choice Awards 2024 dataset using MongoDB queries and the aggregation framework.

## Dataset
Goodreads Choice Awards 2024 Books dataset.

## Objectives
- Explore book categories
- Identify most voted books
- Analyze ratings by category
- Detect authors with multiple nominations
- Analyze popularity of genres
- Study author follower distribution

## Technologies
- MongoDB
- Aggregation Framework
- JavaScript queries

## Main Analyses
1. Books ordered by votes
2. Number of nominated books per category
3. Top 10 books by votes in each category
4. Highest rated books per category
5. Genre popularity analysis
6. Average book price
7. Total votes per category
8. Authors with multiple nominations
9. Author popularity segmentation
10. Winning books per category
